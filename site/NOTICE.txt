- Speech to Text: Whisper tiny by OpenAI, 8-bit ONNX files (encoder_model_quantized.onnx, decoder_model_merged_quantized.onnx) from https://huggingface.co/onnx-community/whisper-tiny
  (a conversion of https://huggingface.co/openai/whisper-tiny). These files are NOT stored in this repository or on this site: your browser downloads them from huggingface.co when you press Record or pick an audio file.
  License status, as found on 2026-11-20: the onnx-community repository declares no license of its own and names openai/whisper-tiny as its base model. The base model's Hugging Face card declares Apache-2.0, and the OpenAI Whisper source repository (https://github.com/openai/whisper, copyright 2022 OpenAI) is MIT-licensed; its text is in whisper/LICENSE-openai-whisper-MIT.txt. Both are permissive licenses that require keeping the notice. The two declarations differ, so both are named here.
  Runtime: transformers.js 4.3.2 (Apache-2.0, whisper/LICENSE-transformersjs-Apache-2.0.txt) with ONNX Runtime Web (MIT, whisper/LICENSE-onnxruntime-web-MIT.txt).
  whisper/transformers.web.min.js is a bundled build of transformers.js (only pipeline and env are exported). A few long identifier strings in it were split with string concatenation and one URL inside an error-message string was altered by escape characters to get past a GitHub push-protection false positive. The URL is a public gist link from the upstream source (src/models/whisper/modeling_whisper.js). It is not a secret.
