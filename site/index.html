Onda

Sensors and small on-device models, in your browser. Everything runs in this tab; photos and camera frames are not uploaded. This is a counterpart to the Android app, which stays the full version (every Android sensor).

Sensor Lab

Shows only what this browser exposes through the Generic Sensor API (Chrome on Android, secure page). Android's own list is longer. A sensor that is missing here may still exist on the phone.

Object Detection

YOLOv8n, 80 COCO classes, confidence 0.25.

Pose Estimation

YOLOv8n-pose, 17 keypoints, confidence 0.40.

Image Classification

MobileNetV2, top-3 of 1000 ImageNet labels, center-cropped. The model (14 MB) loads only when you press the button.

Speech to Text

Whisper tiny (8-bit, OpenAI; see NOTICE for license). Pressing Record or choosing a file downloads the model once, about 41 MB of model files (plus small config files) from Hugging Face (onnx-community/whisper-tiny), and your browser keeps it. Audio is transcribed in this tab and is not uploaded. Up to 30 s, English. This is the first thing on this page that contacts another server.
